# RheoLBM

> ⚠️ **Status:** Active development.

## Prerequisites

- Conan 2
- CMake 4.2 or newer
- A C++23 compiler
- Ninja
- A Vulkan SDK that provides `slangc`
- X11 development libraries on Linux

On Linux, if Conan reports missing packages from `xorg/system`, append the
following option to the first `conan build` or `conan install` command and run it in an
interactive terminal. Conan will use the system package manager and may ask for
your sudo password:

```sh
--conf=tools.system.package_manager:mode=install
```

Make sure the Vulkan SDK is active before configuring. For a LunarG SDK, this
usually means sourcing its environment script:

```sh
source /path/to/vulkansdk/setup-env.sh
```

## Build with Conan

If Conan does not already have a default profile, create it once per development
machine:

```sh
conan profile detect
```

If you already have one, inspect it with `conan profile show` instead of
overwriting local customizations. The profile must describe the compiler CMake
will use. The project uses C++23, so ensure that the profile's `compiler.cppstd`
setting is `23` or pass it on the command line as shown below.

Conan manages GLFW, GLM, the Vulkan headers and loader, yaml-cpp, GDAL, and
their transitive dependencies. ImGui and ImGuiFileDialog remain checked-in
dependencies because the application builds their selected sources and Vulkan
backend directly.

Install the dependencies and build a Debug version:

```sh
conan build . \
    --build=missing \
    --settings=build_type=Debug \
    --settings=compiler.cppstd=23
```

For Release, change the build type. Conan's CMake layout keeps the build
configurations in separate directories:

```sh
conan build . \
    --build=missing \
    --settings=build_type=Release \
    --settings=compiler.cppstd=23
```

The resulting executable is `build/<configuration>/rheo-lbm`.

For an IDE-oriented configure/build flow, install first and use the presets
generated by Conan:

```sh
conan install . \
    --build=missing \
    --settings=build_type=Debug \
    --settings=compiler.cppstd=23

cmake --preset conan-debug
cmake --build --preset conan-debug
```

Before running it, activate Conan's runtime environment so GDAL and PROJ can
find their packaged data files:

```sh
source build/Debug/generators/conanrun.sh
./build/Debug/rheo-lbm
source build/Debug/generators/deactivate_conanrun.sh
```
